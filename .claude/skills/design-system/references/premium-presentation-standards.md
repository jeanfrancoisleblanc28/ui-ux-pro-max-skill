# Premium Presentation Standards

Standards for decks that match the visual and narrative rigor of leading design and strategy firms (Pentagram, McKinsey Visual, BCG, IDEO, Wolff Olins).

## Core Principles

1. **Restraint over decoration** — One idea per slide. Generous whitespace. No ornamental elements that do not carry meaning.
2. **Typographic hierarchy as structure** — Use scale, weight, and tracking to create clear reading order. Prefer 1–2 typefaces maximum.
3. **Narrative clarity** — Every slide advances a single argument. Data supports the story; it does not replace it.
4. **Precision alignment** — Modular grid, consistent margins, intentional optical alignment.
5. **Color with purpose** — Limited palette. Color used for emphasis, categorization, or emotional shift — never for decoration.
6. **Human-centered evidence** — Combine quantitative metrics with territorial or human context (especially relevant for economic development).

## Layout Discipline

- Maximum 3 content zones per slide.
- Prefer full-bleed or near-full-bleed compositions with controlled overlays.
- Use progressive disclosure: title → supporting claim → evidence.
- Section dividers should be sparse and typographic.

## Data Visualization Standards

- Charts must answer one question.
- Label axes and callouts in the same typeface system.
- Prefer direct labeling over legends when possible.
- Annotate the insight, not just the data.
- Color encodes meaning (positive/negative, before/after, category).

## Economic Development Specific Guidance

- Anchor claims in territorial reality (geography, existing assets, local constraints).
- Pair macro context with local proof points.
- Make public-private leverage explicit.
- Show workforce and place-based outcomes alongside investment figures.
- Use before/after or current/future framing for transformation projects.

## Recommended Premium Layout Patterns

| Pattern | Use | Notes |
|---------|-----|-------|
| Editorial Statement | Vision or key message | Large type, minimal supporting text, ample negative space |
| Evidence Stack | Proof points | 3–4 metrics or facts with source and implication |
| Territorial Map + Insight | Regional context | Map or diagram + single clear takeaway |
| Dual Reality | Before/after or challenge/opportunity | Controlled contrast, not visual noise |
| Action Pathway | Next steps or governance | Clear sequence, responsible parties, timeline |

## Typography Recommendations

- Headlines: strong geometric or transitional serif / neo-grotesque sans.
- Body: highly legible sans with good x-height.
- Metrics: tabular figures when available.
- Tracking: slightly open on large display type.

## Quality Checklist

- [ ] One primary message per slide
- [ ] All text is readable at presentation distance
- [ ] Color contrast meets accessibility standards
- [ ] Sources are attributed where claims are made
- [ ] No unused visual elements
- [ ] Consistent margins and alignment across the deck
- [ ] Narrative arc is intact when slides are read in sequence
